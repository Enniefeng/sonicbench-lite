QUICK START

快速开始

评测和质检共用同一个工作台，通过工作模式区分操作流程。

  1. 01选择工作模式新任务选“标注模式”；复核已有结果选“质检验收模式”
  2. 02加载 Case标注模式粘贴脱敏工单行；质检模式粘贴结果 JSON
  3. 03完成任务完成 MOS 与 ELO，或逐项复核并修订已有答案
  4. 04导出结果在结果页复制或下载 JSON，并回填到对应工单
ROLE GUIDE

按角色使用

评测员负责完成新任务；质检员负责复核与修订已有结果。

01

评测员

完成 MOS 与 ELO 评测

  1. 在工作台选择与工单一致的模型数量。
  2. 从在线表格或 Excel 复制整行，粘贴后进入标注。
  3. 依次完成 MOS 和 ELO；缺少必填项时按页面提示定位补充。
  4. 在结果页复制或下载 JSON，再粘回对应工单行。
02

质检员

复核并修订已有结果

  1. 切换到“质检验收模式”，粘贴评测员导出的自包含 JSON。
  2. 逐项检查评分、标签、备注和匿名音频。
  3. 如需调整，修改后查看本次变更清单与 Revision 记录。
  4. 使用“下一项”继续检查，完成后导出修订结果。
INPUT & OUTPUT

输入与输出

下表用于确认每个阶段需要准备和保存的内容。

阶段输入输出／需要保存
评测标注单条脱敏工单行自包含结果 JSON，或带结果的完整工单行
质检验收评测结果 JSON包含修订记录与新版 Revision 的结果 JSON
中途恢复当前浏览器中的本机 Case 历史恢复评分后重新进入结果页导出的 JSON

本机恢复：工作台会在当前浏览器保存脱敏工单与评分草稿；正式交付仍以结果页导出的 JSON 为准。
