# Public release checklist

- [ ] All examples use `example.com` and fictional IDs.
- [ ] No Mapping, work-order output, completed result, token, `.env`, or private URL is tracked.
- [ ] Spreadsheet files contain no hidden sheets, comments, external links, author metadata, or embedded objects.
- [ ] `node test-dynamic-models.js` and `node test-aggregation.js` pass.
- [ ] Repository visibility is changed only after branch, PR, issue, release, Actions log, and Pages review.
- [ ] Secret scanning and push protection are enabled.
- [ ] License choice is approved by the repository owner.
